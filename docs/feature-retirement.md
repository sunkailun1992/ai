# 功能退役与数据边界

个人项目已退役对话式问卷：HTTP 路由、状态机、模板种子、答案解释与自然追问、完成 outbox、问卷派生记忆写入以及对应 Agent 能力均已移除。普通患者分析、可信身份、租户隔离、文件安全、会话记忆和审计继续独立维护。

个人小程序客户端不再作为当前交付对象，客户端目录按用户要求移出开发目录并保留本机恢复能力。服务端已有通用会话、文件与历史认证兼容代码不自动扩大为恢复小程序的授权；新的客户端必须使用已验证的身份合同。

数据清理仅针对个人 PostgreSQL 中退役功能的专属记录及精确关联记录。执行前必须确认旧服务已停止、把目标行备份到 Git 外的受限目录，再在事务内清理并逐项读回；普通 AI 文本记忆、审计和 RAG 来源不得混入清理条件。私有备份、凭据及原文不进入本仓库。

已发布的历史数据库初始化和迁移脚本保留为历史记录，不借退役重写既有 MySQL 历史。当前代码不再注册旧实体、导入模板或调用旧接口；不得从历史脚本重新启用退役业务。现有表结构是否物理删除属于单独数据库迁移，数据清理不以自动 DROP 代替。

验证同时覆盖编译与完整业务回归、Agent 退役端点 HTTP 404、Jar 中无退役类和模板，以及目标数据清理后的独立读回。源码、数据清理、实际制品、部署和浏览器验收分别报告。
